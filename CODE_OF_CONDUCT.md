# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be welcoming and respectful, criticize ideas rather than people, and accept that maintainers may edit or remove comments, commits, code and issues that don't follow it. Harassment, personal attacks, sexualized language or imagery, and publishing others' private information are not tolerated.

It applies in the repository (issues, pull requests, discussions) and wherever someone represents the project.

## Reporting

Report unacceptable behavior to the maintainer, [@jutsuhq](https://github.com/jutsuhq), privately, or through GitHub's [report content](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam) tools. Reports are kept confidential. Maintainers act on them following the Covenant's enforcement guidelines: from a private warning up to a permanent ban.
